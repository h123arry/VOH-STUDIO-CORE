# VOH STUDIO product intelligence

VOH product intelligence turns a high-level objective into concise product decisions without exposing hidden chain-of-thought.

## Signals and outputs

- Product blueprint: purpose, target users, workflows, functional and non-functional requirements, architecture, data model, security, UX, integrations, testing, and deployment.
- Requirement inference: domain-aware defaults for fintech, social, ecommerce, education, gaming, and developer tools, with generic safe defaults for other products.
- Product review: repository-backed gaps for journeys, testing, security, deployment, UX, accessibility, performance, reliability, and completeness.
- Journey model: primary first-value, return, failure/recovery, and domain-specific flows.
- Product score: ten dimensions with findings-backed deductions; never a security guarantee.
- Project graph: product → features → journeys → components → services → APIs → database → dependencies → tests → deployments.
- Roadmap and readiness: foundation, core product, trust, scale, and polish, with blockers surfaced before release claims.
- Natural-language inspection: authenticated project-scoped search over existing workspace evidence.

## Safety and honesty

The engine infers ordinary product requirements, but it does not infer dangerous irreversible actions. Regulated or high-impact behavior remains approval-gated. Scores are heuristic product signals, not certification. External research and competitor patterns must inform original implementations; proprietary code, branding, and protected assets are not copied.

All analysis routes are owner-scoped and use the existing workspace and repository inspection boundaries.
