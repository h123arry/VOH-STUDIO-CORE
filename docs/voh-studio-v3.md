# VOH STUDIO v3

VOH STUDIO v3 connects the product, engineering, and verification layers into one creation engine. A natural-language objective is classified into an internal mode such as build, improve, debug, analyze, design, import, automate, deploy, maintain, research, or document. Users do not need to select a technical workflow.

The creation plan composes the existing engineering brief, capability registry, multimodal input permissions, and visual build loop. It returns the relevant capability families, specialist team, phases, safety gates, verification expectations, and concise explanations without exposing hidden reasoning. The capability catalog remains extensible rather than limiting VOH to a fixed list of project types.

Visual objectives use a reference → build → render → compare → identify differences → improve loop. Imported projects use a takeover flow that maps the repository, identifies risks and debt, and proposes incremental work. Cross-project reuse returns a validated inspection plan and never copies files without ownership and compatibility checks.

The user-facing identity is VOH STUDIO with the tagline **Build. Automate. Create.** Provider-specific runtime identifiers remain only where required by platform infrastructure and are not part of the product experience.
