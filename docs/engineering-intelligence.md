# Autonomous engineering intelligence

VOH STUDIO now has a unified engineering intelligence layer that connects project understanding, product intent, planning, execution, verification, review, recovery, and checkpointing.

## Runtime behavior

For each objective, the layer classifies complexity and capabilities, selects specialist roles, chooses a verification level, builds dependency-aware units, identifies likely impact areas, and records whether an operation needs approval. The orchestrator records this brief as task evidence before implementation begins.

The project analysis route combines repository mapping, cached relevant context, heuristic review findings, impacted files, dependencies, and an evidence-based engineering health signal. The health signal covers build, tests, security, performance, architecture, dependencies, documentation, and deployment. It is explicitly a heuristic and never a certification.

Maintenance objectives produce a safe-mode plan. Production deployment, destructive data operations, credential changes, and external side effects remain protected actions that require the existing approval boundaries and recoverable checkpoints.

## Verification and recovery

Verification is selected as fast, standard, or deep. Simple work receives targeted checks; medium work receives build, relevant tests, and integration checks; large, security-sensitive, release, or production objectives receive deep verification, including broader testing and review expectations. Reliability findings become failure-memory lessons rather than reasons to blindly repeat an approach.

The underlying execution loop remains resumable and evidence-backed: understand, plan, decompose, execute, verify, review, fix, retest, checkpoint, and report.
